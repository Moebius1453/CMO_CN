# 注入式汉化的加固规范与发版统一入库检查

（本条目原为 v4.1.7 输入闪退事故的加固规范；2026-10-17 按 RV-20261016 落地结果补充更新。）

## 一、输入防拉锯（v4.1.7 输入闪退事故）

- **现象与根因**：在搜索想定/任务名输入框输入 `m` 时，引擎日志出现
  `UI Controls Translated count … (Sample: m -> 米)` 每 2.5 秒 +50，累计到 5900 后进程以
  `0xc00000fd`（栈溢出）闪退。机制：DarkUI 自定义输入框不继承 `TextBoxBase`，落进通用文本翻译分支；
  词典里有 `m → 米`，于是引擎把用户正在输入的 `m` 改写成「米」，游戏再写回 `m`，形成无终止拉锯。
- **必须遵守的四条**：
  1. **输入控件正文永不改写**：按类型特征兜底识别（类型名含 `TextBox`/`EditBox`、以 `Edit` 结尾），
     只允许翻译水印/占位符。
  2. **聚焦中或下拉展开中的组合框不改 `Items`**；聚焦中的富文本不动其文档。
  3. **回写拉锯熔断**：同一控件反复写入同一目标值超过阈值（6 次）即永久放弃该控件并留堆栈。
  4. **深度闸门只挂在「游戏事件触发的回写路径」上**，绝不可套在正常控件遍历器上（会静默漏译深层控件）。
- **异常绝不外逃**：注入进游戏进程的回调一旦让异常逃逸，CLR 直接 FailFast（进程瞬间消失、无堆栈）。
  必须内部消化 + 记录（`CMOLocalizer_Crash.log`），且仅当堆栈含本引擎帧时才吞掉。

## 二、发版统一入库检查

- 清单：`docs/RELEASE_MANIFEST.md`（发什么/必须先入库什么/禁止带上什么/发布后自检/回滚）。
- 一条命令：`python scripts/release_check.py`（`--pre` 为打包前预检）。判定逻辑单点：
  `publish_release.py` 复用 `release_check.check_regression_report`，不要在别处再写一份。
- `--static --installer` 与 `--live` **必须分两次运行**：installer 用例会
  `CMOShared.KillProcesses`（先 CloseMainWindow 再 Kill）——那是安装器的正确行为，
  与游戏同时跑会让 live 在 L0-game 阶段假失败。

## 三、2026-10-17 落地补充（RV-20261016 实测得出，六条硬约束）

1. **词典必须能从源重建**：写入显式 LF；同一事实只能有一个源——`legacy_fixes.json` 不得覆盖
   `campaign_ui.json` 的正确值、长标签放 `labels.json`、人工核验过的偏移注入放 `force_offsets.json`
   （且它必须能越过 `identifiers` 过滤）。重跑 `build_dict.py` 必须与已提交词典**字节一致**。
   实测踩到的四个子缺陷：LF→CRLF 造成 +49,427 字节纯换行 churn；非幂等值覆盖导致工坊叠译修复被回退；
   长标签被 `is_script_or_schema` 误判丢弃；offset 7916 被 `identifiers` 静默跳过。
2. **门禁必须能被证伪**：每条 gate 都要有负向用例；空集/零命中要判 FAIL 而不是 `0>=0`。
   典型失效：简报门禁在目标为空时永远绿；历史密钥扫描用 `git log -G<regex>` 受 git 正则方言限制，
   对真实存在的凭据改动零命中（改用按 blob 去重 + `cat-file --batch` 才真正生效）。
3. **部署标记必须是元数据标识符**（方法/类型名）：字符串字面量在 #US 堆是 UTF-16、
   局部常量名会被 csc 内联，两者都搜不到——按 ASCII 搜二进制会得到假红。
4. **先量再改**：perf 类 finding 先做微基准再动代码。实测三组：共享层记忆化收益≈0（噪声内）、
   词库解析单次化收益≈0（解析 10.5MB 只要 51ms，评审高估两个数量级，已回退）、
   页面翻译 12-gram 预过滤 8.5–8.8×（真实页面文本 + 真实词典，输出逐字节一致）。
5. **忽略目录不等于安全**：`.gitignore` 只保护版本库，不保护工作区与产物。凭据扫描必须覆盖
   `__pycache__/*.pyc`、`.env*`、`*.log` 等危险忽略项（真实事故：明文 `sk-` 令牌就藏在被忽略的 `.pyc` 里）。
6. **实机测试边界**（避免「以为测了其实没测到」）：游戏窗口无法被工具提到前台
   （`Focus result: False`），地图/阵营选择层需真人点一次；界面分 WinForms / WPF / 大厅 WebView2
   三层，扫描要分别用 `CTRL_TREE` 与 `WPF_DUMP`；富文本控件（`DarkRichTextBox`）是引擎翻译盲区。
