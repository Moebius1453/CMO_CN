# 每次完成任务后立即 push

用户明确要求（2026-10-14）：“以后每次完成一个任务就 push 一次”。

执行约定：
- 每个 todo 任务达到验收标准后，先 `git commit`，再 `git push origin master`，然后才进入下一个任务。
- 推送失败必须如实上报，不允许用“已提交”冒充“已推送”。
- 本机直连 github.com:443 超时；已在本仓库 .git/config 内配置
  `http.proxy = http://127.0.0.1:7890`（本地代理），push 方能成功。
  若换机器或代理端口变化，先 `curl -x http://127.0.0.1:<port> https://github.com` 探活再推。
