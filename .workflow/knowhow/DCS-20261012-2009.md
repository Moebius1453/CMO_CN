# 决策：打包与发布操作必须严格遵守用户单向指令原则

## 背景
在完成功能开发与验证（如地图汉化、UI修复）时，智能体曾自行调用 `package.sh` 生成分发产物。用户明确指示：“写入项目记忆我没让你打包不要自己打包”。

## 决策内容
1. **严格禁止自作主张打包**：即使功能已开发完成且测试全通，也严禁自动触发 `package.sh`、绿色包打包或任何 Release 动作。
2. **职责边界**：
   - 自动执行范围：功能编码、词库构建、引擎编译、本地部署、实机验证、门禁测试。
   - 用户独占指令范围：打包（`package.sh`）、Tag 发布、GitHub Release 上传。
3. **完成标准**：汇报工作成果与实机证据即可，等待用户决定是否打包分发。
