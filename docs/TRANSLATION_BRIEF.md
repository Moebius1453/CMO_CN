# CMO 汉化翻译规范（翻译员必读）

本文件是《Command: Modern Operations》汉化工程的翻译契约。所有译文必须满足本规范。

## 0. 任务形态

你拿到一个分片文件 `dict/chunks/chunkNN.json`，形如：

```json
{ "687910": "° C", "25028": "Zulu", "40158": "Alts" }
```

- **键**是引擎字符串池偏移，**值**是英文原文。你只需翻译**值**。
- 输出文件写成 `{"英文原文": "中文译文"}` 的扁平 JSON，**键必须是英文原文逐字符一致**。
- 不要输出偏移。不要改动英文侧（包括空格、标点、`{0}`、`%s`、`&`）。

## 1. 语气与文风

- 目标读者是**中文现代兵棋玩家**，熟悉"条令/交战规则/航路点/编队"这类词。
- 采用**解放军标准军语**与**指令式简洁风格**，不用书面白话，不用营销腔。
- 界面标签求短：能两字不用三字（`Delete`→`删除`，不是"删除掉"）。
- 整句消息求自然：像中文母语者写的系统提示，不像英文语序直搬。
- **禁止**在汉字之间加空格，**禁止**保留英文虚词（the/of/and/for/with/to/is/are）。

## 2. 缩写处理

军事缩写优先"中文全称 (缩写)"，第一次出现处保留英文缩写：

| 英文 | 译法 |
|---|---|
| AAW | 防空作战 (AAW) |
| ASuW | 反水面作战 (ASuW) |
| ASW | 反潜作战 (ASW) |
| RoE | 交战规则 (RoE) |
| EMCON | 辐射控制 (EMCON) |
| WRA | 武器投射权限 (WRA) |
| AAR | 空中加油 (AAR) |
| ToT | 抵达目标时间 (ToT) |
| RTB | 返航基地 (RTB) |
| OODA | 观察-判断-决策-行动 (OODA) |

**标签位置**（列头、按钮、Tab 页签）空间紧张，可只用中文全称，省略括号缩写。
**不改**：型号编号（F-16C、Su-35S、AIM-120D、055型）、图层名（Stamen、OpenTopoMap）、
专有名词（Tacview、Steam Workshop）。

## 3. 度量与单位

保留英文单位符号不译：`nm`（海里）、`kt`（节）、`ft`（英尺）、`m`、`kg`、`lb`、`sec`、`min`、`hr`。
中文语境下可写 `空` + 单位，如 `Max Range (nm)` → `最大航程 (nm)`。

## 4. 必须逐字保留的成分

| 成分 | 例子 | 规则 |
|---|---|---|
| 格式化占位符 | `{0}` `{1}` `%s` `%d` `{0:F2}` | 原样保留，位置可调整 |
| 快捷键助记符 | `&File` | 译作 `文件(&F)` |
| 省略号 | `...` | 保留 ASCII 三点 |
| 前后空格 | `" has ASW weapons"` | **保留首尾空格**（代码拼接用） |
| 换行 | `\n` | 保留 |
| HTML 标签 | `<b>` `<br>` `</td>` | 原样保留 |
| 冒号 | `:` | 中文侧用全角 `：` |

**首尾空格示例**：
```
"Ship has " -> "舰船已 "        ← 保留尾部空格
" nm to Bingo" -> " 海里至返航油量 (Bingo)"   ← 保留首部空格
```

## 5. 上下文推断

字符串是孤立取出的，需按 CMO 语境判断：

- 出现 `nm / kt / ft / °` → 度量标签
- 出现 `Side / Unit / Contact / Mission` → 想定编辑器术语
- 出现 `Database / DB3000 / CWDB` → 数据库查看器
- 出现 `Error / Warning / Cannot / Invalid` → 校验或错误消息
- 出现 `Sensor / Mount / Loadout / Magazine` → 装备挂载界面
- 驼峰或全小写单词（`Alts` 除外）多半是内部符号，**但仍要译**——若确实无法确定，
  按该词在兵棋语境的常见义翻译。

## 6. 质量标准（会被机械校验）

翻译完成后会运行校验脚本，以下情况会被打回重做：

1. 译文不含任何汉字
2. 汉字之间出现空格
3. 残留英文虚词：`the of and for with from to in on at by is are`
4. 括号不配对
5. 占位符数量与原文不一致（`{0}` `%s` 等）
6. 首尾空格与原文不一致

## 7. 输出格式

在 `dict/src/` 下新建文件，文件名用分片号：

```
dict/src/chunkNN.json
```

内容为单个扁平 JSON 对象，UTF-8 无 BOM：

```json
{
 "Zulu": "标准时",
 "Alts": "高度",
 "Back": "上一步",
 "Next": "下一步"
}
```

**不要**写解释、注释、markdown 代码块或多余字段。必须是可 `json.load` 的纯对象。
