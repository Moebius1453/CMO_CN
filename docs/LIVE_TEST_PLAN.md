# 《Command: Modern Operations》v4.0.0 全量真机测试方案

本方案面向《Command: Modern Operations（现代行动：指挥）》v4.0.0 汉化版，采用**「进程外 Win32 视觉/键鼠驱动 (`GuiDriver.exe`) + 进程内 CLR UI 线程受控反射指令通道 (`CMOLocalizer.dll`) + 实时未译词条审计器 (`CMOLocalizer_LiveAudit.log`)」**三位一体的真机实测方法，对游戏全部核心界面、菜单、子菜单、剧本树、作战简报、地图国家海域注记、实战剧本推演及核心业务子窗口进行全量真机验证。

---

## 一、测试架构与工具链

1. **进程外驱动器 (`src/tools/GuiDriver.cs` -> `build/GuiDriver.exe`)**
   - 窗口枚举与置顶：`EnumWindows`、`ShowWindow(SW_RESTORE)`、`SetForegroundWindow`、获取物理像素矩形 `GetWindowRect`。
   - 键鼠模拟：`SetCursorPos` + `mouse_event`（单击/双击/右键）、`keybd_event` / `SendKeys`。
   - 高清实机截图：支持按指定 `HWND` 窗口区域或全屏截取 PNG 图像，自动保存至 `evidence/live/`。

2. **进程内受控测试引擎 (`CMOLocalizer.dll` 内置 `TestCommandWorker`)**
   - 运行在 `Command.exe` 内部，监听游戏根目录下的 `CMOLocalizer_Cmd.txt`，在主窗体 UI 线程 (`MainForm.BeginInvoke`) 精确执行测试动作并将结果写入 `CMOLocalizer_CmdResult.json`：
     - `DUMP_MENUS`：递归导出主菜单栏 (`MenuStrip`) 全部顶层菜单、二级子菜单、三级子菜单的实机当前 `.Text` 属性与汉化率。
     - `SHOW_MENU:<index>` / `SHOW_SUBMENU:<i1>:<i2>`：在实机画面上直接展开对应的顶层菜单与子菜单下拉框，配合 `GuiDriver.exe` 截取高清实机展开图。
     - `CLICK_MENU:<path>`：按路径或名称在 UI 线程直接触发菜单项点击（如打开【加载想定】【数据库查看器】【推演选项】【阵营条令】【任务编辑器】【编辑阵营】【作战序列】【事件编辑器】等）。
     - `LOAD_SCEN:<relative_path>`：在【加载想定】窗口或主界面直接加载指定 `.scen` 剧本文件进入战场。
     - `DUMP_OPEN_FORMS`：导出当前所有已打开的 WinForms / WPF 窗口及内部全部子控件的实机文本快照。

3. **实时未译词条审计器 (`CMOLocalizer_LiveAudit.log`)**
   - 在实机运行和打开各个窗口的过程中，任何经由 `TranslateString` 处理但未能翻译为中文的界面可见英文词条（排除纯数字、坐标、装备代号与路径），均实时记录其控件类型、所在窗口与原文，做到**「测出一处、定位一处、热修一处、复测一处」**。
